# Nightwire starter crates

Five curated crates of freely licensed dance music for [Nightwire](https://subtxtlabs.com/nightwire.html), added from the app's **Add music** menu.

| Crate | BPM | Tracks |
|---|---|---|
| First Mix | 120–124 | 35 |
| Deep & Melodic | 113–123 | 36 |
| Tech House | 124–128 | 36 |
| Nu-Disco & Funk | 108–120 | 36 |
| Techno | 128–135 | 36 |

The audio is in this repository's [releases](../../releases/tag/starter-crates): one zip per crate, plus a `manifest.json` with each zip's size and SHA-256.

## Licensing

Every track is licensed **CC BY**, **CC BY-SA** or **CC0**, and is redistributed unchanged. Each licence was checked on the track's source page on the [Free Music Archive](https://freemusicarchive.org) or the [Internet Archive](https://archive.org/details/netlabels) netlabel collection. Per-track artists, licences and sources are in [CREDITS.md](CREDITS.md) and in the `CREDITS.txt` inside each zip.

If you are an artist listed here and want a track removed, please open an issue.
